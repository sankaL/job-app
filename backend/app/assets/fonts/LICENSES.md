# Bundled export fonts

Static Latin subsets of the fonts below are used by the PDF export styles in
`app/services/export_styles.py`. They are bundled because the backend image only
ships DejaVu fonts. Files were taken from the Fontsource distribution.

| Font | Used by | License |
|---|---|---|
| Gelasio (metric-compatible with Georgia) | Classic | SIL Open Font License 1.1 |
| Carlito (metric-compatible with Calibri) | Modern | SIL Open Font License 1.1 |
| Source Sans 3 | Compact | SIL Open Font License 1.1 |
| EB Garamond | Executive | SIL Open Font License 1.1 |
| Lato | Minimal | SIL Open Font License 1.1 |
